## Пилотная серия публикаций

### Публикация 1. Обзор проекта

**Тема:** AI-консультант по каталогу: почему обычного чат-бота недостаточно.

**Формат Threads:** Carousel.

**Изображения:**
- `telegram-01-recommendation.jpg`
- `telegram-02-budget.jpg`

Показываем реальную работу AI-консультанта: от исходного запроса до уточнения бюджета.

### Публикация 2. Техническое решение

**Тема:** Почему vector search не должен выбирать товары в каталоге.

**Формат Threads:** Image post.

**Изображение:**
- `telegram-03-comparison.jpg`

Скриншот иллюстрирует пользовательский результат сравнения товаров. Он не является самостоятельным доказательством внутренней реализации SQL, ранжирования или векторного поиска. Эти сведения подтверждаются технической документацией проекта.

### Публикация 3. Ошибки и ограничения

**Тема:** Запрос «подешевле» сломал красивую архитектуру.

**Формат Threads:** Image post.

**Изображение:**
- `telegram-04-tradeoff.jpg`

Скриншот иллюстрирует сценарий обсуждения экономии и компромиссов при выборе телевизора.

Он не должен представляться как доказательство конкретной ошибки с выдуманным числовым ограничением, если эта ошибка не показана непосредственно на изображении. Для описания ошибки используются результаты тестирования и документация проекта.

## Правила использования

1. Использовать существующие локальные файлы.
2. Не генерировать новые изображения вместо реальных скриншотов.
3. Не менять содержание скриншотов.
4. Не приписывать скриншотам неподтверждённые результаты.
5. Перед публикацией проверять существование и технические параметры каждого файла.
6. Загружать изображения через `StorageUploader` на публичное HTTPS-хранилище, доступное Threads API.
7. Не публиковать изображения, если загрузка или проверка URL завершилась ошибкой.

## Исходный демонстрационный сценарий

1. «Нужен телевизор 65 дюймов для фильмов и PS5. Что посоветуешь?»
2. «А есть варианты до 150 тысяч рублей?»
3. «Сравни две лучшие модели из твоего ответа»
4. «Какая из них лучше именно для PS5 и почему?»
5. «Если сэкономить ещё 20–30 тысяч, что я потеряю?»

Для пилотной серии используются четыре подготовленных скриншота, соответствующих выбранным этапам диалога.
