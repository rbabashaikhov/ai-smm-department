# AI Catalog Consultant — knowledge package

Источник правды для будущих SMM-агентов. Факты собраны из актуального публичного репозитория проекта и истории наших чатов разработки.

Правило: если факт не подтверждён материалами этой папки, агент не должен его придумывать.

Проект сейчас называется **AI Catalog Consultant**. Он вырос из Samsung TV AI Consultant; в Phase 4G публичное позиционирование нейтрализовано. Текущая реализация остаётся TV-specific.
